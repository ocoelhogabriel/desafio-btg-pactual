# desafio-btg-pactual

Este repositório contém a solução para o **Desafio BTG Pactual**, desenvolvido inteiramente em **Java**. O objetivo deste projeto é demonstrar habilidades em programação, arquitetura de software e resolução de problemas propostos durante o desafio técnico.

## Tecnologias Utilizadas

- **Java** (100%): Toda a lógica de negócio, estruturas de dados e fluxos do projeto foram implementados na linguagem Java, garantindo robustez, desempenho e facilidade de manutenção.

## Descrição do Projeto

O projeto foi desenvolvido para atender aos requisitos descritos pelo desafio técnico do BTG Pactual. As principais funcionalidades implementadas incluem:

- Implementação de regras de negócio conforme as especificações do desafio.
- Estruturação clara e bem definida do código-fonte.
- Utilização de boas práticas de desenvolvimento Java.

## Como Executar

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/ocoelhogabriel/desafio-btg-pactual.git
   ```
2. **Acesse o diretório do projeto:**
   ```bash
   cd desafio-btg-pactual
   ```
3. **Compile e execute o projeto:**
   - Utilizando Maven:
     ```bash
     ./mvnw clean install
     ./mvnw spring-boot:run
     ```
   - Ou utilizando sua IDE de preferência.

4. **Acesse a aplicação:**
   - Por padrão, estará disponível em `http://localhost:8080` (ou conforme configuração do projeto).
